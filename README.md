# The Long Night

The Long Night is a first-person survival game prototype built in Unreal Engine. The project is inspired by atmospheric wilderness survival games such as The Long Dark, with a focus on isolation, cold environments, scarce resources, exploration, and moment-to-moment survival decisions.

## Current Project Status

- First-person character movement, camera control, sprinting, and interaction traces.
- Player controller setup using Unreal Enhanced Input.
- Interactable actor interface for world objects and pickup items.
- Inventory component with item stacking, item removal, item checks, total weight, and maximum carry weight.
- Data-driven item definitions using Unreal Primary Data Assets.
- Basic item categories such as food, water, tools, clothing, weapons, medicine, fuel, and miscellaneous items.
- UMG-based interaction prompt and inventory debug widgets.
- Main menu, pause menu, game mode, game instance, and game state classes.

## Technologies Used

- Unreal Engine 5.8
- C++
- Unreal Gameplay Framework
- Enhanced Input
- UMG
- Slate / SlateCore
- Primary Data Assets
- Actor Components
- Unreal Interfaces
- AI Module
- StateTree and Gameplay StateTree plugins
